TEMA · Digital Crown ile değişir
MOD

Saatte ekrana dokunmak kod yağmurunu açıp kapatır, kronu çevirmek temayı değiştirir. Burada ekrana tıkla ya da kronu kullan.

SAATE YÜKLEME

  1. App Store Connect'te Admin yetkili bir API anahtarı oluştur, değerleri GitHub secret'larına ekle. Mac gerekmez.

  2. GitHub Actions'ta setup, ardından beta iş akışını çalıştır. Derleme bulutta yapılır ve TestFlight'a yüklenir. iPhone'daki TestFlight'tan saatine kur.

  3. Saatte Ayarlar → Genel → Saate Dön → 1 saat sonra seç. Böylece DevFace ekranda kalır, Always-On'da sade moda geçer.

  4. Modular Ultra kadranına DevFace komplikasyonunu ekle, Action Button'a da "Uygulamayı Aç: DevFace" kestirmesi ata. Tek basışta geri gelir.

Bilmen gereken kısıt: Apple üçüncü parti saat kadranlarına izin vermiyor. DevFace bu yüzden kadran gibi davranan bir watchOS uygulaması ve sistem kadranlarına eklenen komplikasyonlar olarak yazıldı.
